# example

The agent fills this note from the operator's card or request. It is not an
operator form.

## Operator-observed problem

What the operator sees today, in their words, with enough detail to reproduce
it.

## Desired behaviour

What should be true when this is done, including the public contract and the
cases that must not change.

## Acceptance

How the operator can see it is true: named tests, commands, fixtures and
compatibility checks. A library has no UI acceptance suite; its Gherkin and
verify stage carry the contract.
